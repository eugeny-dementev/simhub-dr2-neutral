# Security policy

## Supported versions

Security fixes are provided for the latest released major version.

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| Earlier | No |

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private
[security advisory form](https://github.com/eugeny-dementev/simhub-dr2-neutral/security/advisories/new)
with the affected version, impact, reproduction steps, and any proposed fix.
Do not include credentials or unrelated personal data.

You should receive an acknowledgement within seven days. The maintainer will
coordinate validation, remediation, release timing, and credit. Please avoid
public disclosure until a fixed release or coordinated advisory is available.
