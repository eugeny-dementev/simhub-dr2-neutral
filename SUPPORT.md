# Support

Please read the [installation](docs/INSTALLATION.md) and
[troubleshooting](docs/TROUBLESHOOTING.md) guides first. Search existing issues
before opening a new one.

For a reproducible bug, include:

- Plugin, SimHub, Windows, and DiRT Rally 2.0 versions.
- Controller name and whether built-in input is enabled.
- Exact starting gear, expected result, and observed **Last result** text.
- Minimal relevant `[DR2Neutral]` log lines with personal paths removed.
- Steps that reproduce the problem while stationary.

GitHub Discussions is not currently enabled; normal usage questions may be
opened as issues. Security vulnerabilities must not be reported publicly—use
[SECURITY.md](SECURITY.md).
